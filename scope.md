# Scope

Mini SOC Dashboard is a local educational security laboratory.

In scope:
- Local Flask app
- SQLite
- Authentication events
- Failed-login detection
- Brute-force simulation
- Synthetic events sent to the local SIEM API (scripts/simulate_events.py)
- Security alerts
- Dashboard investigation

Out of scope:
- Third-party systems
- Live traffic from other applications or targets (events are synthetic)
- Unauthorized access
- Credential attacks against real users
- Destructive or denial-of-service testing

Environment: 127.0.0.1
